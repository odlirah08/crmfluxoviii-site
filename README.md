# crmfluxoviii.tech

Site de vendas do FLUXO VIII CRM. Arquivos estáticos publicados pela Hostinger (hPanel → Avançado → GIT, branch `main`, diretório `public_html`).

- `index.html`: a página inteira (estilos e script dentro dela).
- No fim do `index.html` ficam o endereço do CRM (`CRM_URL`) e os links do Asaas de cada plano (`PLANS`).
- `.htaccess`: força HTTPS e o endereço sem "www".
